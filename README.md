# Iran Stock Analyzer - Streamlit MVP

این یک نمونهٔ اولیه (MVP) از یک «تحلیل‌گر سهام ایران» است که با Streamlit نوشته شده و می‌تواند داده‌های تاریخی قیمت سهام را (از فایل CSV) بارگذاری کند و چند اندیکاتور پایه را محاسبه و نمایش دهد.

فایل‌های اضافه شده:
- app.py: اپ Streamlit (رابط فارسی)
- src/data_fetcher.py: بارگذاری CSV و نقطهٔ شروع برای fetcher
- src/indicators.py: پیاده‌سازی SMA, RSI, MACD
- requirements.txt
- README.md (راهنمای نصب و استفاده به فارسی)

تذکر: برای دریافت خودکار دادهٔ TSE/MCD نیاز به توسعهٔ بیشتری دارد؛ فعلاً حالت بارگذاری CSV برای MVP فراهم شده است.
